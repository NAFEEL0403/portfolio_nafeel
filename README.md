# 💼 Nafeel Aohamed N - Portfolio

A modern, responsive, and production-ready **Developer Portfolio** built with **React.js**, **Vite**, and **Tailwind CSS**. This portfolio showcases my skills, projects, experience, certifications, and achievements as a **Full Stack Developer** and **Computer Science Engineering Student**.

## 🌐 Live Demo

👉 https://portfolio-nafeel.vercel.app/

---

## ✨ Features

- 🌙 Dark & Light mode with theme persistence
- 🎨 Modern UI with red and blue gradient theme
- 📱 Fully responsive across all devices
- ⚡ Smooth animations using Framer Motion
- 👨‍💻 Interactive Hero section with typing animation
- 🛠️ Technical skills categorized by domain
- 💼 Professional experience timeline
- 🚀 Featured project showcase
- 📜 Certifications and achievements
- 📄 Resume preview and download
- 📬 Contact form with EmailJS integration
- 🔝 Scroll progress indicator and Back-to-Top button
- ✨ Glassmorphism design and smooth transitions

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/NAFEEL0403/Portfolio.git
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
